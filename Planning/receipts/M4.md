## Delivered

- **One `--moves` flag** (§4.1, P2, P7): asked moves (SAN or UCI), `best`, `topN`, the
  verdict keywords (`playable`, `inaccuracies`, `mistakes`, `blunders`, `unplayable`) and
  `all`, combined as a union, deduplicated, in typed order. Search A's width K and its
  node budget follow the selection; whole-board keywords are warned about in `--help`.
- **Verdict scale** (§4.2): best / okay / inaccuracy / mistake / blunder; playable = best
  or okay; `playable_truncated` when every returned line is playable.
- **Tactic and opportunity** (§4.3–4.5): a tactic is a forced mate or a material gain;
  allows a tactic on the opponent's refutation; an opportunity is an only move by its
  margin over the second-best move. Tactic lines carry contributions and labels;
  `root_motifs` carry the root facts a move uses (Re8# uses the `back_rank_weakness` on
  g8, `indirect`).
- **Move reports** (§4.6, §5): one move report per reported move, filtered for relevance
  (contributing motifs only, positional changes held at the end and net over the walk);
  report v6 with `schema/report.v6.schema.json` and `schema/moves.v6.schema.json`.
- **Four outputs** (P9, §10): `--json` chooses JSON or text, `--full-report` chooses the
  full report or the move reports. The move report text never says "candidate".
- **Checks**: the projection check in `tools/validate_report.py` (every move report fact
  is a full-report field or a filter of one, recomputed independently); semantic checks
  for verdict, tactic, opportunity, selection order and `playable_truncated`.
- **Fixtures**: F32–F39, E19–E22; all F fixtures re-blessed on report v6 and `--moves`
  (FIXTURES.md §1, §3, §9).
- **Docs**: README (flags, four outputs, verdict scale, playable, tactic, opportunity),
  `third_party/DEPENDENCIES.md`, DBC files, `CURRENT_STATE.md`.
